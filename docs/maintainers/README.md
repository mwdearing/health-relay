# Maintainer notes (inherited from upstream, not used by HealthRelay)

The files in this directory and the [maintainer guide](../maintainer-guide.md) describe the upstream Apple Health AI Bridge release process (App Store review notes, distribution readiness). HealthRelay does not use them: it ships signed beta builds on request (GitHub Releases carry notes, not IPA files) and installs the receiver from `main`. See [versioning](../versioning.md) for the real process.

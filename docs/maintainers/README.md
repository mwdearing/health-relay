# Maintainer notes (inherited from upstream, not used by HealthRelay)

The files in this directory and the [maintainer guide](../maintainer-guide.md) describe the upstream Apple Health AI Bridge release process (App Store review notes, distribution readiness). HealthRelay does not use them: it ships unsigned IPAs from GitHub Releases and installs the receiver from `main`. See [versioning](../versioning.md) for the real process.

They are kept unchanged because guardrail tests read them.

# HealthRelay brand assets

HealthRelay is a private fork of Apple Health AI Bridge; these assets belong to the fork, not to the upstream product.

HealthRelay's own mark: a deep-teal tile, a white pulse line, a mint chevron (data relayed onward).
These files are generated by [`../../tools/generate_healthrelay_icon.py`](../../tools/generate_healthrelay_icon.py)
(Pillow only) and must stay reproducible from it. The upstream Health Bridge assets were removed;
see [`../../NOTICE`](../../NOTICE).
